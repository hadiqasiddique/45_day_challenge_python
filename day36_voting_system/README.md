# 🗳️ Voting System in Python

This project is a **simple Voting System** built in Python.  
It allows users to vote for their favorite option, view results, and exit the application.  
By the end, you’ll have a fully functional **command-line voting application**.  

---

## Features
- **Vote** → Users can vote for their favorite option from a predefined list.  
- **View Results** → Users can view the vote tally for each option.  
- **Exit** → Users can quit the application at any time.  

---

## Python Concepts Covered
- **Functions** → `display_menu`, `vote`, `display_results`, `main`.  
- **User Input** → Using `input()` to capture user selections.  
- **Lists** → Used to store options and vote counts.  
- **Control Structures** → `if/else`, `loops`, and validation checks.  

---

## Modules & Tools Used
- No external libraries required 
- Uses only **Python standard built-ins**:  
  - `print()` for output  
  - `input()` for user interaction  
  - `enumerate()` for iterating with indexes  

---

## How to Run
1. Clone/download this repository.  

2. Run the program with:
  
   ```bash

   python voting_system.py

3. Follow the interactive menu to vote, view results, or exit.
