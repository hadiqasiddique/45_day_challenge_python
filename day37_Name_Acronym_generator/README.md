# Name Acronym Generator

## 📌Project Overview
The **Name Acronym Generator** is a simple Python application that generates acronyms from full names. It takes the first letter of each word in a full name, converts it to uppercase, and combines them to form a concise and memorable acronym. This can be useful in professional, academic, and personal contexts where abbreviations are needed.

## Features
- **User Input Handling:** Accepts full names from the user.
- **String Manipulation:** Splits the input into words, extracts initials, and converts them to uppercase.
- **Acronym Creation:** Combines initials to generate the final acronym.
- **Interactive Loop:** Continuously accepts input until the user chooses to exit.

## Python Concepts Covered
- String manipulation methods (`split()`, `upper()`, `join()`)
- Loops and conditionals (`for`, `if-else`)
- Functions and return statements
- User input and output handling

## How to Use
1. Run the program using Python.
2. Enter a full name when prompted.
3. View the generated acronym.
4. Type `exit` to quit the program.

## Example
Enter your full name (or type 'exit' to quit): Hadiqa Siddique
Acronym for John Doe: HS

## Requirements
- Python 3.8+
