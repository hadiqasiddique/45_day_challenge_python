# 📅 Python Calendar Application

## 📌Overview
This is an **intermediate-level Python project** that allows users to manage events in a calendar.  
Users can **add, view, and delete events** easily through a simple menu-driven interface.

---

## Features
-  Add events with **title, date, and description**
-  View all events in the calendar
-  Delete events by their title
-  User-friendly text-based menu system
-  Uses **Object-Oriented Programming (OOP)** principles

---

## Concepts Covered
- **Classes & Objects** → Encapsulation of `Event` and `Calendar`  
- **File Handling (optional extension)** → Save and load events  
- **Datetime Module** → Parse and validate dates  
- **Lists** → Store multiple events  
- **Input/Output** → Interactive menu-based system  

---

##  How to Run
1. Clone or download this repository.  
2. Open a terminal in the project folder.  
3. Run the script:
   ```bash
   python calendar_app.py
