# Python Tip Calculator

## Project Overview
The Tip Calculator is a simple Python program that calculates the tip amount based on a given bill and desired tip percentage.  
It is especially useful in restaurants and service industries where tipping is common.

By the end of this project, you will have a fully functional tip calculator that you can use in everyday scenarios.

---

## **Key Features**
1. **User Input:** Users can input the bill amount and desired tip percentage.  
2. **Tip Calculation:** Calculates the tip based on user input.  
3. **Total Amount Calculation:** Adds the tip to the original bill to display the total amount.

---

## **Python Concepts Covered**
- User input using `input()` function  
- Arithmetic operations for tip calculation  
- User-defined functions for modular code  
- Exception handling for invalid inputs  

---

## **How to Run**
1. Ensure Python is installed on your system.
2. Save the code as `tip_calculator.py`.
3. Run the program:
   ```bash
   python tip_calculator.py
4. Enter the bill amount and tip percentage when prompted.

5. View the calculated tip and total bill amount.

Example:

Welcome to Tip Calculator

Enter your bill amount: 200.06

Enter tip percentage: 1.5

Bill Amount: $200.06

Tip Percentage: 1.5%

Tip Amount: $3.00

Total Bill Amount: $203.06
