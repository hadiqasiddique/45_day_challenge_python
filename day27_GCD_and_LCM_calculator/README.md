**Project Name: GCD and LCM Calculator**

**Description:**

A Python program that calculates the Greatest Common Divisor (GCD) and Least Common Multiple (LCM) of two numbers.

Uses Python's built-in math module for GCD and a custom formula for LCM.

Handles invalid input using exception handling.

**Features:**

1. Calculate GCD of two integers.

2. Calculate LCM of two integers.

3. Display results in a clear format.

4. Validates user input and handles errors gracefully.

**Requirements:**

- Python 3.8 or higher

**How to Run:**

- Save the code below as gcd_lcm_calculator.py.

- Open Command Prompt or Terminal in the file's folder.

- Run the command:
python gcd_lcm_calculator.py

**Example Run:**

=== GCD and LCM Calculator ===

Enter the first number: 20

Enter the second number: 30

The GCD of 20 and 30 is: 10

The LCM of 20 and 30 is: 60
