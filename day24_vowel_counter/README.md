📄 **README – Vowel Counter Python Project**
📌**Overview**

The Vowel Counter Project is a simple Python program that counts the number of vowels in a given string.
This project demonstrates basic string manipulation, loops, and conditional statements in Python.

🎯 **Features**

- Vowel Counting – Counts vowels (a, e, i, o, u) in both uppercase and lowercase.

- User Interaction – Takes input from the user and displays the result.

- Simple & Beginner-Friendly – Easy to understand for Python newcomers.

🛠 **Python Concepts Used**

String Manipulation – Iterating through each character and checking for vowels.

Loops – Used for loop to process each character.

Conditional Statements – Used if condition to identify vowels.

Functions – Defined a separate function for vowel counting.

Built-in Functions – Used input() and print().

🧰 **Tools & Libraries**

Built-in Functions: input(), print()

String Methods: Membership operator (in) to check if a character is a vowel.

📋 **Project Steps**

- Define Function – Create a function to count vowels in a string.

- Take User Input – Prompt the user to enter a string.

- Count Vowels – Use a loop and conditions to count vowels.

- Display Result – Show the total number of vowels.

💻 **Example Output**
===== Vowel Counter =====

Enter a string: Today is Sunday and it is a holiday
The number of vowels in the string is: 12

🚀 **How to Run**

- Install Python (if not already installed).

- Save the code below in a file named vowel_counter.py.

- Open the terminal/command prompt and run:

    python vowel_counter.py
