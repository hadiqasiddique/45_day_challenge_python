# Leap Year Checker in Python

A simple Python program to check whether a given year is a leap year or not.  
This project is great for beginners learning **conditional statements**, **user input**, and **error handling** in Python.
---

## 📌 Features

- **Check Leap Year:** Determines if a year is a leap year based on the correct rules.
- **User Input:** Allows the user to enter any year for checking.
- **Error Handling:** Handles invalid inputs gracefully.
- **Simple and Beginner-Friendly:** Great for learning `if-else` and Python basics.

---

## 📚 Python Concepts Used

1. **Conditional Statements:** `if`, `else`, and logical operators (`and`, `or`).
2. **User Input:** `input()` function to take data from the user.
3. **Type Casting:** Using `int()` to convert input from string to integer.
4. **Error Handling:** Using `try-except` to catch and handle invalid inputs.

---

## ⚙️ How Leap Year is Determined

A year is a leap year if:
- It is divisible by 4 **and** not divisible by 100  
  **OR**
- It is divisible by 400

**Examples:**
- ✅ 2000 → Leap year  
- ✅ 2024 → Leap year  
- ❌ 1700 → Not a leap year  
- ❌ 2019 → Not a leap year
