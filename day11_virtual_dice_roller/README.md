# 🎲 Virtual Dice Roller (Python)

## 📌 Overview
The **Virtual Dice Roller** is a Python application that simulates rolling two dice.  
It uses Python's built-in `random` module to generate truly random results between **1** and **6** for each die.  
Perfect for board games, probability studies, or simple simulations.

---

## Features
- **Dice Simulation:** Rolls two dice and displays individual values.
- **Randomness:** Uses `random.randint()` to ensure fair results.
- **User Interaction:** Roll the dice repeatedly or quit anytime.
- **Total Calculation:** Displays the sum of both dice after each roll.

---

## 🛠️ Technologies Used
- **Python 3.x**
- **random module** (built-in)
- Built-in functions: `input()`, `print()`
