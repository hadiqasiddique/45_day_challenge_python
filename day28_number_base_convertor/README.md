# 🔢 Number Base Converter (Python)

A simple and interactive **Number Base Converter** built with Python.  
This program allows users to convert numbers between **Decimal, Binary, and Hexadecimal** systems using Python’s built-in functions and a command-line interface.

---

##  Features
- Convert **Decimal → Binary**
- Convert **Decimal → Hexadecimal**
- Convert **Binary → Decimal**
- Convert **Hexadecimal → Decimal**
- User-friendly **Command Line Interface (CLI)**
- Error handling for invalid inputs

---

##  Requirements
- Python 3.8 or higher  
(No external libraries required – uses only Python standard library)

---

##  How to Run
1. Clone this repository or copy the files.
2. Open a terminal (or PowerShell) and navigate to the project folder.
3. Run the program:

```bash
python number_base_converter.py
