# 🎲 Dice Roll Histogram

A Python program that simulates rolling a die multiple times and displays the results as a histogram.  
This helps visualize the randomness and distribution of dice rolls.

## Features
- Simulates rolling a die **n** times.
- Plots a histogram showing the **frequency** of each dice face.
- Uses Python's built-in `random` module for randomness.
- Uses **Matplotlib** for data visualization.

## Requirements
- Python **3.8+**
- Matplotlib library

Install Matplotlib (if not installed):
```bash
pip install matplotlib

##How to Run

- Save the code in a file named dice_roll_histogram.py.

- Open a terminal in the same directory.

- Run the program:
python dice_roll_histogram.py

- Enter the number of times you want to roll the die.

- View the generated histogram.

##Example

Input:

Enter the number of times to roll the die: 10

Output:

A histogram appears showing the distribution of dice rolls.

X-axis → Dice faces (1 to 6)

Y-axis → Frequency of each face appearing
