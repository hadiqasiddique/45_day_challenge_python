**Text File Analyzer Python Project**
**📌Project Overview**

The Text File Analyzer is a Python program designed to analyze text files and provide statistical insights.

This project allows users to:

- Count the number of lines in a text file.

- Count the total number of words.

- Identify and display the most frequent words in the text.

- This project helps practice Python concepts such as:

- File handling – reading and processing text files.

- String manipulation – cleaning and splitting text.

- Collections module – using Counter to count word frequencies.

**Features**

1. Read File

- Safely reads a text file and handles file not found errors.

2.  Count Lines

- Returns the number of lines in the file.

3. Count Words

- Returns the total number of words in the file.

4.  Most Frequent Words

- Finds the top N most frequently occurring words in the file.

- Cleans text by removing punctuation and converting to lowercase.

5. Display Statistics

- Combines all functions to display line count, word count, and most frequent words.

**How to Run**

- Copy the code below into a Python file named text_file_analyzer.py.

- Run the file in VS Code or any Python IDE.

- Enter the file path of the text file to be analyzed when prompted.
