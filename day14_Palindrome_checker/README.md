# Project Name: Palindrome Checker
**Description:**
A simple Python program that checks whether a given string is a palindrome.

The program ignores spaces and is case-insensitive.

**Features:**

- Menu-driven interface.

- Handles invalid input gracefully.

- Ignores spaces and letter case.

- Beginner-friendly code.

**Requirements:**

- Python 3.8 or higher.

**How to Run:**

- Download the script file palindrome_checker.py.

- Open Command Prompt or Terminal in the file's folder.

- Run the command:
python palindrome_checker.py

**Example Run:**

=== Palindrome Checker ===

1. Check a string

2. Exit

Enter your choice: 1

Enter a string to check: Madam

'Madam' is a palindrome.

=== Palindrome Checker ===

1. Check a string

2. Exit

Enter your choice: 2

Exiting...
