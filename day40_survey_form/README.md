# Simple Survey Application

## 📌Project Overview
The **Simple Survey Application** is a Python project designed to collect user feedback through a set of predefined questions. Users can answer the survey, and the application stores and displays all responses. This project demonstrates fundamental concepts of Python, including classes, objects, dictionaries, loops, and user input handling.

## Features
- **Conduct Survey:** Users can answer a set of predefined questions.
- **Store Responses:** All responses are stored in a structured dictionary.
- **Display Results:** Collected responses are displayed in a readable format.
- **Interactive Menu:** Users can conduct surveys, view results, or exit.

## Python Concepts Covered
- Classes and Objects
- Dictionaries
- Loops and Conditional Statements
- User Input
- Object-Oriented Programming

## Tools and Modules
- Built-in Python functions: `input()`, `print()`
- Classes and methods for structured programming

## How to Use
1. Run the program using Python.
2. Use the interactive menu to:
   - Conduct the survey.
   - View all collected responses.
   - Exit the application.
3. Enter your responses to the survey questions when prompted.
4. View the results in a readable format.
