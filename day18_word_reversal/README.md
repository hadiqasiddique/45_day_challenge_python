# Word Reversal Project in Python

This project is a simple Python program that **reverses the order of words** in a given sentence.  
It’s a beginner-friendly exercise to practice **string manipulation** and **list operations**.

## Features
- Takes a sentence from the user.
- Splits the sentence into a list of words.
- Reverses the order of the words using **slicing** (`[::-1]`).
- Joins the reversed list back into a readable sentence.
- Handles spacing correctly.

---

## Concepts Covered
- **String Manipulation**
  - `split()` – split a sentence into words.
  - `join()` – join a list of words into a sentence.
- **List Slicing** – reverse a list with `[::-1]`.
- **User Input** with `input()`.
- **Functions** in Python.

---

## How the Program Works
1. **Split the sentence** into words using `split()`.
2. **Reverse the list** of words using slicing.
3. **Join the words** back together with spaces using `" ".join()`.
4. **Return the reversed sentence**.

## Example
Enter a sentence: today is June 4th

Reversed sentence: 4th June is today
