# 🌍 Spanish Translator (Python Project)

## 📌 Overview
This project is a simple **Spanish Translator** built in Python using **Object-Oriented Programming (OOP)** and **string manipulation**.  
It allows users to input English text and receive Spanish translations for predefined words.  
If a word is not found in the dictionary, the original English word is returned unchanged.  

---

##  Features
- Translate English text into Spanish  
- Handles multiple words (sentences)  
- Keeps untranslated words as-is  
- Interactive **menu-driven program**  
- Beginner-friendly & lightweight  

---

## Python Concepts Used
- **Classes & Objects** → Encapsulating translation logic  
- **Dictionaries** → Storing English → Spanish word mappings  
- **String Manipulation** → Splitting and joining text for translation  
- **Input/Output** → Interactive menu for users
