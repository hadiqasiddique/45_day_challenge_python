**Bank Management System**
📌 **Overview**

The Bank Management System is a simple Python-based console application that allows users to manage basic banking operations such as creating an account, depositing funds, withdrawing money, and checking account balances.
It is designed for educational purposes to demonstrate file handling, functions, and user input validation in Python.

✨ **Features**

1. Create New Account – Register new customers with account details.

2. Deposit Money – Add funds to an existing account.

3. Withdraw Money – Safely withdraw funds while ensuring sufficient balance.

4. Check Balance – View the available balance in an account.

5. Exit System – Close the program.

🛠️ **Technologies Used**

- Python 3.8+ – Core programming language.

- File Handling – To store and retrieve account data.

- Basic Error Handling – Prevents crashes from invalid inputs.
