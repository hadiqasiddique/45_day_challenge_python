**Project Name: Prime Number Checker**
**Description:**

- A Python program that checks whether a given number is a prime number.

- Utilizes an optimized method by checking divisibility up to the square root of the number.

- Handles invalid input and allows repeated checks until the user chooses to exit.

**Features:**

- Check if a number is prime.

- Optimized divisor checking using square root logic.

- Handles invalid input gracefully.

- Loop-based user interaction until quit option selected.

**Requirements:**

- Python 3.8 or higher.

**How to Run:**

- Save the code below as prime_number_checker.py.

- Open Command Prompt or Terminal in the file's folder.

- Run:
python prime_number_checker.py

**Example Run:**

Enter a number (or Q to quit): 23

23 is prime.

Do you want to check another number? (yes/no): yes

Enter a number (or Q to quit): 18

18 is not prime.

Do you want to check another number? (yes/no): no
Exiting...
