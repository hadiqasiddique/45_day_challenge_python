# Python Unit Converter

A beginner-friendly Python project that converts between **Length**, **Weight**, and **Temperature** units.  
This project demonstrates **functions**, **user input handling**, and **conditional logic**.

---

## Features

- **Length Conversion**
  - Inches → Centimeters
  - Centimeters → Inches
- **Weight Conversion**
  - Pounds → Kilograms
  - Kilograms → Pounds
- **Temperature Conversion**
  - Fahrenheit → Celsius
  - Celsius → Fahrenheit

---

## Formulas Used

### Length
- **Inches → Centimeters**: `cm = inches * 2.54`
- **Centimeters → Inches**: `inches = cm / 2.54`

### Weight
- **Pounds → Kilograms**: `kg = pounds * 0.453592`
- **Kilograms → Pounds**: `pounds = kg / 0.453592`

### Temperature
- **Fahrenheit → Celsius**: `C = (F - 32) * 5 / 9`
- **Celsius → Fahrenheit**: `F = (C * 9 / 5) + 32`

---

## How It Works

1. The program displays a **main menu**:
- Length Conversion

- Weight Conversion

- Temperature Conversion

2. The user selects a category (1/2/3).

3. A **sub-menu** appears for the chosen category (e.g., Inches to Centimeters).

4. The user enters a numeric value.

5. The program outputs the converted result.
