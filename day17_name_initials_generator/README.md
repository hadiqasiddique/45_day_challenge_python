# 🅰️ Name Initials Generator (Python)

A simple Python project that generates **initials** from a given full name.  
It automatically handles extra spaces and converts all initials to uppercase.

---

## 📌 Features
- Takes a full name as input.
- Removes leading/trailing spaces automatically.
- Converts initials to **uppercase**.
- Menu-driven interface with options to generate initials or exit.
- Handles both lowercase and uppercase names.

---

## 🛠️ Concepts Used
- **Functions** (`def`) for modular code.
- **String methods**:
  - `.strip()` → remove extra spaces
  - `.split()` → break into words
  - `.upper()` → make letters uppercase
- **List comprehension** for efficient processing.
- **While loop** for main menu.
- **If-else statements** for flow control.

---
